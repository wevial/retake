# Retake gallery captions (proposed, Ko-approved image set)

All artwork is AI-generated demo art, made for these examples. Screenshots are from the Hermes Desktop Retake workspace.

1. **1-project-overview.png** — Projects hold your images as assets, each with its own version history.
2. **2-mark-a-change.png** — Drag a box on the image and describe the change for that region. Retake records the note with the box, then you pick a model and generate a revision.
3. **3-compare-versions.png** — Swipe between the original (v1) and a lighting revision (v2) made with Nano Banana Pro. Models can drift from the request, so Compare is how you check what actually changed.
4. **4-version-lineage.png** — Every revision keeps its parent. Here v2 and v3 were made with Nano Banana Pro, and v4, branched from v2, with GPT Image 2.
